홈 화면에 추가하는 방법

1
화면 아래쪽 가운데의 공유 버튼 을 눌러주세요.
공유 버튼이 안 보이면 ⋯ 버튼을 먼저 누르면 나와요.
2
목록을 위로 올려 "홈 화면에 추가" ＋ 를 눌러주세요.
안 보이면 목록 맨 아래 "편집"에서 추가할 수 있어요.
3
오른쪽 위 "추가"를 누르면 완료!
